# Protocol reference and attribution

The eModul menu implementation was checked against the official eModul API
documentation and the MIT-licensed TECH Controllers integration by Mariusz
Ostoja-Swierczynski. The latter was used as a reference for API conventions,
confirmation values and Home Assistant control platforms.

Source: https://github.com/mariusz-ostoja-swierczynski/tech-controllers

The original license notice is retained below. This project is an independent
community integration. Icons are Material Design Icons provided by Home Assistant;
manufacturer graphical assets are not bundled in the menu card.
